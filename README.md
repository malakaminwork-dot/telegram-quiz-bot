# 🤖 بوت تلجرام للاختبارات التعليمية

بوت متكامل لإنشاء وإجراء الاختبارات التعليمية على تلجرام.

## ✨ المميزات
- إنشاء اختبارات بواسطة المدرسين
- إضافة أسئلة نصية وصور
- أداء الاختبارات من قبل الطلاب
- عرض النتائج فوراً
- واجهة سهلة الاستخدام

## 🚀 التنصيب السريع

### 1. على Render.com
1. انقر على الزر أدناه:

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy)

2. املأ المعلومات:
   - **Name**: telegram-quiz-bot
   - **Environment**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python app.py`

3. أضف متغيرات البيئة:
   - `BOT_TOKEN`: توكن البوت من @BotFather
   - `ADMIN_IDS`: أرقام هوية المدرسين (اختياري)

4. انقر على **Deploy**

## ⚙️ الحصول على توكن البوت

1. ابحث عن `@BotFather` في تلجرام
2. أرسل `/newbot`
3. اتبع التعليمات
4. احفظ التوكن الذي يعطيك إياه

## 📞 الدعم

للأسئلة والاستفسارات، راجع الوثائق أو تواصل مع المطور.
